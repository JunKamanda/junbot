# JunBotbyBokwete

Ce projet est un Expert Advisor (EA) pour MetaTrader 5.

## 1) Installer MetaTrader 5
- Télécharge MetaTrader 5 depuis ton broker.
- Installe MetaTrader 5 sur Windows.
- Connecte-toi à un compte de démonstration ou réel.

## 2) Importer le bot
- Ouvre MetaEditor dans MetaTrader 5.
- Va dans Fichier > Ouvrir.
- Sélectionne le fichier :
  - junbotbyBokwete.mq5
- Compile avec F7.

## 3) Lancer le bot
- Ouvre un graphique XAUUSD (or Gold).
- Choisis un timeframe : M5 ou M15.
- Dans la fenêtre Navigation, ouvre Expert Advisors.
- Trouve le bot "BOKWETE BIG BOT".
- Fais glisser le bot sur le graphique.
- Active "Autoriser les Expert Advisors" et "Autoriser le trading automatique".

## 4) Vérifier les paramètres
- Paramètres de lot, TP, SL, trailing et filtres.
- Vérifie que le symbol est bien XAUUSD.
- Vérifie que le spread est correct.

## 5) Conseils
- Démarre d’abord en démo.
- N’ouvre pas trop de volume au début.
- Teste avec un petit lot.

## 6) IMPORTANT
Ce type de code dépend de MetaTrader 5, il ne s’exécute pas comme un programme Windows classique.

Le fichier .cpp a été copié comme .mq5 pour préparation.
